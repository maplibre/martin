Building a basemap from OpenStreetMap

This builds a basemap tileset from an OpenStreetMap extract, with the layers and attributes using the Shortbread schema, so that VersaTiles styles can draw them. The configuration is a port of Planetiler's shortbread.yml, and Martin's tests use the 67 examples of its shortbread.spec.yml.

More information on the config used

The osm section is described in OpenStreetMap PBF Sources, the shapefile section in Shapefile Sources.

One layer differs from Planetiler's: boundaries also takes the member ways of admin_level 2 and 4 boundary relations, many of which have no tags of their own, with the lowest admin_level of the way and its relations. Planetiler's shortbread.yml reads only tagged ways and leaves this as a TODO. The configuration reads the relations through relation membership.

  1. Download an extract, for example Berlin from Geofabrik, and the ocean polygons of the whole world from osmdata.openstreetmap.de, about 900 MB:

    curl -LO https://download.geofabrik.de/europe/germany/berlin-latest.osm.pbf
curl -LO https://osmdata.openstreetmap.de/download/water-polygons-split-3857.zip

  2. Save this as shortbread.yaml, next to both downloads:

    shortbread.yaml 
    shapefile:
  sources:
    ocean:
      path: water-polygons-split-3857.zip
      maxzoom: 14
      layers:
        ocean:
          geometry: polygon
          attributes: []
