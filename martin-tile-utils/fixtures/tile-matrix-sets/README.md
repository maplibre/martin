# Tile matrix set documents

`tests/grid.rs` checks every built-in tile grid against its document here.

The OGC grids are the registry's own files from <https://schemas.opengis.net/tms/2.0/json/examples/tilematrixset/>.
`NZTM2000Quad.json` is the grid [LINZ](https://github.com/linz/NZTM2000TileMatrixSet) publishes, in the same shape, as [morecantile](https://github.com/developmentseed/morecantile/tree/929ca50407260e52ada0176d1d4c12a12ee251d1/morecantile/data) carries it from GDAL.
